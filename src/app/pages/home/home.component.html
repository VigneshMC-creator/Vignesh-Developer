ABOUT

How I approach development.

I like to understand the complete request path before changing a single method.

My development approach starts with understanding the complete request lifecycle. I trace HTTP requests through controllers, validation, service methods and repository or data-access logic before changing code.

When extending an application, I review the existing implementation, follow DTOs and mapping profiles, inspect EF Core and SQL interactions, and verify how data moves through each layer. I pay close attention to API contracts, backward compatibility, validation and predictable persistence.

My technical interests include .NET architecture, EF Core change tracking, SQL performance, asynchronous programming, API integrations and Angular connectivity. I use AI-assisted tools as part of development, but I still review, test and make sure I can explain the code I work on.
