01 / A little about me

Curious by nature.
Engineer by practice.

I like understanding how the pieces fit together: clean interfaces, reliable APIs, data that makes sense, and code that another developer can follow.

My focus is full-stack development in the .NET ecosystem. I work with backend concepts, frontend application structure, and relational data, while continuously strengthening the fundamentals behind them.

I'm especially interested in API design, Entity Framework Core, application architecture, and system design. I learn best by building, testing, debugging, and documenting what I discover.

I also use AI-assisted tools as part of my workflow — while keeping code understanding, review, and engineering decisions my responsibility.
